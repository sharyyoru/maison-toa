IGeneralInvoiceRequestManager::CreateGeneralInvoiceRequestManager property
This property has a Restful Webservice representation only!
Creates an instance of the main IGeneralInvoiceRequestManager interface.
 
To delete/invalidate this interface instance, the counterpart property PutDestructGeneralInvoiceRequestManager must be explicitly called, since the pIGeneralInvoicetRequestManager address has a global scope and is not automatically destructed.
