IGeneralInvoiceRequest::SetTiers method
Sets the Tiers Garant (TG), Tiers Soldant (TS) or Tiers Payant (TP) mode together with the VAT number and some other data.
 
  • In the TG case a prepaid amount can be defined, such that the due amount is calculated as «amount + reminder amount - prepaid amount».
  • In the TS case or TP case the prepaid amount must be zero, as the debitor is not the patient (that prepaid the amount!)!

Calling argument description
[in] TiersModeType eTiersMode The tiers mode ("Tiers Garant" or "Tiers Payant") is set from the TiersMode enumeration list
[in] YesNoType ePatientAllowTS The Boolean ePatientAllowTS confirms that the patient allows the usage of Tiers Soldant (TS).
Furthermore, it implies the existence of a salary cession document signed by the patient and included as PDF attachment.
Please note, that if ePatientAllowTS=enNo then the request should not be processed at the insurance's site but rejected due to the missing approval.
[in] YesNoType eAllowTPModification The Boolean eAllowTPModification gives or denies the placet for the health care insurance to correct quantities of supplied services.
 
The service quantity can be changed in the range R0+ (positive real numbers including zero), which changes the amounts of individual services as well as the total invoice amount and the vat accounting.
Please note that if eAllowTPModification=enNo, the entire request should be rejected if the insurance company questions one or more services.
[in] BSTR bstrVatNumber The VAT number of the biller as given by the "Swiss Federal Tax Administration". if he possesses one.
 
Both forms the old 6-digit number as well as the new UID dependent number are allowed. The latter one can be given in its full form, as UID, or just the digits whereas the last digit is automatically expanded if missing.
[in] double dAmountPrepaid The prepaid amount.
The due amount is calculated as «amount + reminder amount - prepaid amount»
 
As of version 450, the prepaid amount is fixed to 0.00 in the TP case. If this rule is violated then an error is returned from the finalizing step Finalize.
[out,retval] VARIANT_BOOL *pbStatus Return status of the method. If pbStatus is VARIANT_FALSE then an error occurred and GetAbortInfo should be called to retrieve the error string.
