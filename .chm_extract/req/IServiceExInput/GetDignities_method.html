IServiceExInput::GetDignities method
This method has a Restful Webservice representation only!
Method for collecting all dignity data covered by the IServiceEx interface and returned as JSON array.
 
Please note that IServiceExInput::GetDignities takes over the functionality of the iterator pair IServiceExInput::GetFirstDignity / IServiceExInput::GetNextDignity with a single call, making the latter superfluous.

[HTTP result status] 200 Return status 200 signals a successful method call
204 Return status 204 (noContent) signals that the end of an iteration is reached
>= 400 Return status >= 400 signals an unsuccessful function call. The returned JSON{errorCode: code, errorText:"text"} supplies the error message the same as GetAbortInfo() would do.
Calling argument description
[in] BSTR bstrGLN Input search parameter criterion acting on the provider's GLN.
 
Use the wildcard symbol (*) to include all records, supply an empty string to not use the GLN as a search criterion.
[in] BSTR bstrQLCode Input search parameter criterion acting on the Qualitative Dignity.
 
Use the wildcard symbol (*) to include all records, supply an empty string to not use the Qualitative Dignity as a search criterion.
[out] BSTR *pbstrGLN The first EAN number fulfilling the search criterion.
[out] BSTR *pbstrQLCode The first Qualitative Dignity fulfilling the search criterion.
[out,retval] VARIANT_BOOL *pbStatus Return status of the method. If pbStatus is VARIANT_FALSE the end of data is reached
