ResidenceBeforeAdmission enumeration type
Enumerates the defined admission locations where the patient is coming from encoded by a terminal set of tokens
Set of enumeration values 14 elements
enAdmissionHome: 0 the admission location is home
enAdmissionHomeSpitex: 1 the admission location is home but having a spitex care as support
enAdmissionHospitalSame: 2 the admission location is the same hospital as the current location
enAdmissionHospitalOther: 3 the admission location is a different hospital to the current location
enAdmissionRetirementHome: 4 the admission location is a retirement home
enAdmissionNursingHome: 5 the admission location is a nursing home
enAdmissionPsychiatricClinicSame: 6 the admission location is the same psychiatric clinic as the current location
enAdmissionPsychiatricClinicOther: 7 the admission location is a different psychiatric clinic to the current location
enAdmissionRehabClinicSame: 8 the admission location is the same rehabilitation clinic as the current location
enAdmissionRehabClinicOther: 9 the admission location is a different rehabilitation clinic to the current location
enAdmissionBirthHouse: 10 the admission location is a birth house
enAdmissionCorrectionalFacility: 11 the admission location is a correctional facility
enAdmissionOther: 12 the admission location is not mentioned above
enAdmissionUnknown: 13 the admission location is unknown
