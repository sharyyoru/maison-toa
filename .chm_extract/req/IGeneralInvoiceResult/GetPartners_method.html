IGeneralInvoiceResult::GetPartners method
This method has a Restful Webservice representation only!
Method for collecting all partner addresses covered by the IGeneralInvoiceResult interface and returned as JSON array.
 
Please note that IGeneralInvoiceResult::GetPartners takes over the functionality of the iterator pair IGeneralInvoiceResult::GetFirstPartner / IGeneralInvoiceResult::GetNextPartner with a single call, making the latter superfluous.

Calling argument description
[out] PartnerType *pePartnerType The type of BfS record for which the number=name pair is supplied.
